## 1. 레퍼런스 프레임 분석 (`assets/reference_frame.png`)

레퍼런스 프레임 실측 좌표(1920×1080 기준). 오버레이는 이 실측을 벗어나지 말 것.

| 요소 | 대략 bbox | 오버레이 영향 |
|---|---|---|
| **발화자 얼굴** | 얼굴 중심 x≈920, y≈380; 얼굴 폭 ≈220px | 세이프존 x=780→1160 절대 침범 금지 |
| **발화자 어깨/상체** | x=680→1200, y=520→1080 | 몸통 세이프존 |
| **오른손 제스처** | x=650→870, y=520→800 (인사·강조 손) | 오버레이가 손 위로 얹히면 어색 — 좌측 오버레이는 x≤560 유지 |
| **맥북 노트북 (좌하단)** | x=0→460, y=680→1080 | **좌측 하단 오버레이 영역과 충돌** — 하단은 노트북 상판 라인(y≈660) 위쪽만 사용 |
| **마이크 헤드** | x=1060→1240, y=380→600 | 중앙-우측 상단 충돌 — 우측 상단 오버레이는 마이크 뒤로 빠지거나 오프셋 |
| **붐암 (우측)** | x=1200→1920, y=200→500 (사선) | 우측 상단 오버레이 영역 대각선 절단 — 상단은 사용 불가 |
| **머그컵 (우하단)** | x=1560→1780, y=830→1030 | 우측 하단 오버레이는 컵을 피해 x≤1540 또는 컵 위 y≤820 |
| **배경 조명** | 따뜻한 앰버 백라이트 (2700K–3000K) | 그린 오버레이가 극적으로 대비됨 (GTC 톤에 유리) |
| **발화자 rim light** | 얼굴 우측에서 앰버 rim | 좌측(반대편)에 그린 rim을 추가하면 twin-light 룩 |

**핵심 결론**: 좌측 오버레이는 **상단부(y=100→640)에 집중**, 우측 오버레이는 **하단부(y=560→1000)에 집중**. 이 프레임에서는 "좌우 대칭 스트립"이 아니라 **좌상단 + 우하단의 대각선 배치**가 정답.

## 2. 캔버스 & 재조정된 세이프존

- 캔버스: **1920 × 1080 (16:9)**
- **피사체 세이프존**: x=680→1200, y=200→1080 (얼굴+상체+제스처 손 여유 포함). 어떤 오버레이도 이 안으로 들어오지 않음.
- **좌상단 오버레이 영역**: x=96→640, y=120→640. 노트북 상판(y≈660)에 걸치지 않도록 y≤640.
- **우하단 오버레이 영역**: x=1260→1824, y=560→1000. 마이크 헤드(y≤600)와 머그컵(x≥1560, y≥830)을 피함.
- **HUD 라인**: 상단 세이프 y=48–72, 하단 세이프 y=1020–1050 (전 씬 공통 브랜드 라인).

## 4. 프리롤 (00:00.000 이전, 옵션 300ms)

- 전 화면에 얇은 스캔라인 sweep + 저음 서브 임팩트 1발.
- HUD 라인 fade-in 30% opacity.
- 발화자 원본은 `filter: brightness(0.55) saturate(0.7)`로 잠긴 상태에서 시작.

## 5. 씬별 연출

### S1 · Datestamp (00:00.000–00:02.480, 2.48s)

**분위기**: 팟캐스트 온에어 램프가 켜지는 순간. 발화자 손인사와 함께 화면에 정보 큐가 들어옴. "이 방송이 무엇을 얘기하는가"를 8초 안에 결정짓는 첫 두 초.

**피사체 처리**
- 0.00–0.40s: 발화자 원본 `brightness(0.55)` → `1.0` 회복 (curve `--ease-precision`).
- 0.40s 이후: 원본 유지. **그린 rim light**를 얼굴 좌측(x≈760, y=280→560)에 SVG 매트 + 2px feather + `--nv-green-glow` opacity 0.35로 합성 → 앰버 백라이트와 twin-light.
- 발화자 뒤 배경(원목 벽·서가)에 **얇은 그린 스캔 라인 하강 1회** (700ms, 상→하). 발화자 얼굴은 마스크로 제외.

**좌상단 오버레이 (x=96→640, y=120→640)**
- **y=120**: 라벨 `PROLOGUE · 001` — `--fs-label` 22px, UPPERCASE, letter-spacing 0.18em, `--nv-mist`.
- **y=180**: 얇은 세로 룰 2px, 높이 40px, `--nv-green`.
- **y=240**: 날짜 스탬프 `2022 . 11 . 30` — `--fs-hero` 168px는 이 영역엔 크므로 **96px 축소(=--fs-headline)** 로 세로 3줄 스택:
  - `2022`
  - `. 11`
  - `. 30`
  - 각 줄 line-height 1.0, tabular-nums, `--nv-white`, 점(.)은 `--nv-green`.
- **y=560**: 캡션 `SEOUL · KST` — `--fs-caption` 20px, `--nv-mist`, 앞에 그린 도트 4px.

**우하단 오버레이 (x=1260→1824, y=560→1000)** — 마이크 붐암 아래, 머그컵 위
- **y=560**: 얇은 가로 룰 폭 320px, `--nv-steel`, opacity 0.6.
- **y=580**: 데이터 스트립 3개 라벨 (세로 스택, 32px 간격):
  - `EPISODE · 01`
  - `AI · MARKET REPORT`
  - `RUNTIME · 00:08`
  - 각각 `--fs-label` 22px, `--nv-mist`. `EPISODE · 01`은 `--nv-white`로 강조.
- **y=760**: 얇은 진행 바 — 전체 폭 320px, `--nv-steel` 트랙 + `--nv-green` fill, 인트로 8초 동안 좌→우 채워짐. Sub-second timer 함께 표시: `00:00 / 00:08` `--fs-ticker` 28px.

**모션**
1. 0.00s: 좌상단·우하단 미세한 배경 카드(`--nv-ink` 92% opacity, 24px 라운드) fade-in (300ms). 카드는 오버레이 뒤 살짝 어두운 안착면 — 발화자 스튜디오 배경과 대비 확보.
2. 0.10s: `PROLOGUE · 001` 라벨 + 세로 룰 클립 마스크 상→하 (250ms, `--ease-precision`).
3. 0.35s: 날짜 스탬프 3줄이 위→아래 stagger로 등장 (`2022` → `. 11` → `. 30`), 각 120ms 간격, `back.out(1.7)`. tabular-nums.
4. 0.80s: 우하단 3개 데이터 라벨 좌→우 mask reveal (각 80ms 간격, 총 240ms).
5. 1.00s: 우하단 진행 바 활성화. 8s 전체 걸쳐 채워짐 (`linear`).
6. 1.20s: 발화자 뒤 배경에 그린 스캔 라인 1회 하강 (700ms, `sine.inOut`).
7. 2.30s (out -180ms): 날짜 스탬프에 pulse (scale 1→1.02→1, 180ms).
8. 2.48s: 하드 컷 (1프레임 화이트 플래시).

**브랜드 라인 (전 씬 공통)**
- 하단 좌 (x=96, y=1032): `NVIDIA` 워드마크 SVG, 높이 22px, `--nv-green` 100%, opacity 0.9. 인트로 내내 고정.
- 하단 우 (x=1720, y=1032): 챕터 표시 `01 / 04` — `--fs-label`, `--nv-mist`.
- 상단 좌 (x=96, y=56): `[ ● REC · LIVE ]` — 8px 그린 도트(0.5s blink) + `--fs-label` — 팟캐스트 온에어 모티프.
- 상단 우 (x=1824-widthAuto, y=56): `NVDA · REALTIME` + tick `--fs-label`, `--nv-mist`.

**사운드 큐**
- 0.00s: 저음 서브 임팩트 + 클릭 tick.
- 0.35s: 각 숫자 등장마다 mechanical tick (약음).
- 1.00s: 진행 바 활성 subtle whir.
- 2.30s: 서브 폭발 프리버스트.

### S2 · ChatGPT Genesis (00:02.480–00:04.730, 2.25s)

**분위기**: 발화자가 손인사에서 말하기로 전환. 우측 마이크 옆에 프롬프트 창이 켜지며 대화가 시작되는 시각적 은유. ChatGPT teal이 잠깐 등장 후 NVIDIA 그린이 삼킴.

**피사체 처리**
- 발화자 정상 노출 유지. 좌측 그린 rim light 유지.
- 발화자 뒤 배경만 미세 desat(-8%)로 뒤로 물러남. 얼굴은 그대로.
- 앰버 백라이트 위에 teal 헤어라이트 미세 합성(300ms 유지 후 자연 감쇠).

**좌상단 오버레이 교체 (x=96→640)**
- 라벨: `PROLOGUE · 001` → `LAUNCH · 2022.11.30` — 200ms 문자 스크램블 트랜지션.
- **y=240** 히어로 카피: `ChatGPT` — `--fs-headline` 96px, `--nv-white`. 앞에 blinking 커서 `▍` `--chatgpt-teal` `#10A37F` (400ms 주기).
- **y=340** 서브 라인: `A conversation begins.` — `--fs-sub` 48px → 이 영역엔 크므로 **32px 축소**, `--nv-mist`, `JetBrains Mono` regular.
- **y=440** 얇은 그린 언더라인이 좌→우 스트로크(3.70s에), 폭 320px, 4px.

**우측 마이크 옆 프롬프트 창 (x=1260→1720, y=580→900)** — 다이제틱 배치: 마이크 붐암 앞으로 떠오르는 UI
- 폭 460px × 높이 260px. `--nv-graphite` `#14181C` 배경, 96% opacity, 12px 라운드, 얇은 1px `--nv-steel` 스트로크.
- **헤더**: 좌측 3개 회색 도트(traffic light 스타일 모노톤) + 우측 미니 마크(원+3점 실루엣, `--nv-mist`) — **OpenAI 공식 로고 사용 금지, 실루엣 은유만**.
- **본문 (mono, `--fs-caption` 20px, `--nv-white`)**:
  - 라인 1: `> Hello, GPT.` (타이핑 780ms, 문자당 60ms)
  - 라인 2 (blinking): `▍`
- 창 아래 `y=920`: 캡션 `NOV.30 · 2022 · SF, USA` — `--fs-label`, `--nv-mist`. (진행 바는 계속 유지)

**모션**
1. 2.48s: 화면 전체 화이트 플래시 1프레임 → 좌 라벨 스크램블 시작 (200ms).
2. 2.55s: 좌 `ChatGPT`▍ 히어로 카피 마스크 리빌 좌→우 (350ms, `--ease-precision`). 커서 blink 시작.
3. 2.55s: 우측 프롬프트 창 scale 0.94→1 + opacity 0→1 (280ms, `back.out(1.4)`), 마이크 붐암 앞으로 z-order 상단.
4. 2.83s: 서브 라인 `A conversation begins.` fade-up (200ms).
5. 2.90s: 프롬프트 창 안 `> Hello, GPT.` 타이핑 (780ms, 문자당 mechanical key tick).
6. 3.70s: 좌측 히어로 카피 아래 그린 언더라인 좌→우 스트로크 (500ms, `expo.out`, `--nv-green-glow`).
7. 4.30s: 프롬프트 창 헤더의 미니 마크가 teal → 그린으로 컬러 전환 (200ms) — "GPT의 파장이 NVIDIA로 넘어간다"는 시각적 브릿지.
8. 4.55s: 화면 전체 chromatic aberration 120ms + 그린 파티클 8개가 프롬프트 창에서 발화자 얼굴 방향으로 튀어감 (짧게).
9. 4.73s: 하드 컷 (1프레임 그린 플래시).

**사운드 큐**
- 2.48s: 화이트 플래시 스윕.
- 2.90s: 타이핑 mechanical tick (약음).
- 3.70s: 언더라인 스트로크 whoosh.
- 4.55s: 서브 폭발 예비 (S3 프리부팅).

### S3 · Ignition (00:04.730–00:08.020, 3.29s)

**분위기**: 팟캐스트 하이라이트 인트로의 클라이맥스. "폭발"이라는 자막에 시각적 폭발이 매칭. 발화자는 여전히 정중앙에서 미소, 그 주변으로 시가총액 급등의 증거가 밀려 들어옴.

**피사체 처리**
- 4.73–5.13s: 발화자 뒤에서 **방사형 그린 글로우** 폭발 (radial gradient `--grad-green-beam`, 발화자 얼굴 원점, opacity 0→0.65→0.30). 폭 800px.
- 발화자 실루엣 우측(붐암 앞 x≈1000)에도 그린 rim 스트로크 추가 → 좌우 twin green rim.
- 배경 원목 서가에 그린 파티클 40개가 좌하단→우상단 대각선으로 흐름 (`sine.inOut`, 4s loop). 얼굴/상체 마스크로 제외.
- 앰버 백라이트가 순간적으로 그린으로 시프트 후 원래 톤 복귀 (400ms).

**좌상단 오버레이 교체 (x=96→640)** — 시가총액 스탯 존
- **y=120**: 라벨 `MARKET CAP · NVDA` — `--fs-label`.
- **y=170**: 카운트업 스탯 (2단계, tabular-nums)
  - 처음 800ms: `$420B` — `--fs-headline` 96px, `--nv-white`.
  - 이후 800ms에 걸쳐 `expo.out`로 `$5,500B`까지 카운트. 마지막 값은 `--nv-green-glow`로 컬러 전환 + pulse.
- **y=310**: 상승 화살표 아이콘(24×32, `--surge-amber`) + `+1,209%` — `--fs-sub` 축소 40px, `--surge-amber` `#FFB020`.
- **y=380**: 캡션 `2022.11 → 2025.10` — `--fs-caption` 20px, `--nv-mist`, 화살표 포함.
- **y=440**: 얇은 앰버 언더라인 폭 320px, 좌→우 stroke draw (500ms).

**우하단 오버레이 교체 (x=1260→1824, y=560→1000)** — 라인 차트 & 티커
- **y=560**: 라벨 `PRICE ACTION · NVDA` — `--fs-label`.
- **y=600–860**: 미니 라인 차트, 폭 500px × 높이 260px, `--nv-graphite` 배경 88% opacity, `--nv-steel` grid 라인 opacity 0.3.
  - 라인: 좌하단→우상단, `--grad-line-chart` (`#3F6600` → `#76B900` → `#B4FF3A`) 스트로크 4px. strokeDashoffset 1.6s, `power2.inOut`.
  - 정점에 앰버 파티클 스파클 8발, `back.out(2)`.
  - x축 라벨: `'22 · '23 · '24 · '25` (`--fs-caption`).
- **y=900**: 티커 marquee — `NVDA · $5.5T · +1,209% · > KOSPI · > CAC · > DAX` 좌우 스크롤, `--fs-ticker` 28px, `--nv-green-glow`. 폭 500px 내 무한 루프.

**보조 배경 그래픽 (피사체 침범 없음)**
- 좌우 극단 x=0→80, x=1840→1920에 얇은 GPU 다이 실루엣 (`--nv-green-deep`, opacity 0.12) 세로 배치.
- 이미 언급된 그린 파티클 흐름.

**모션**
1. 4.73s: 화면 그린 플래시 1프레임 → 방사형 폭발 (400ms, `expo.out`).
2. 4.85s: 좌 라벨 `MARKET CAP · NVDA` slide-in (200ms).
3. 4.90s: 좌 스탯 `$420B` mask reveal (250ms).

## 6. 후처리 (전 씬 공통)

- **Bloom**: 그린/앰버/틸 계열만 (radius 24px, threshold 0.7, intensity 0.6). 앰버 백라이트에는 별도 적용 안 함(발화자 하이라이트가 뜨는 것을 방지).
- **Film grain**: monochrome 3%.
- **Vignette**: edge 20% 다크닝 — 팟캐스트 스튜디오 원본이 이미 밝으므로 시네마 톤 유지.
- **Chromatic aberration**: 씬 전환 및 임팩트 프레임에 120–200ms.
- **Scan lines**: 우측 프롬프트 창/차트 컨테이너 내부에만 opacity 0.04.
- **Color grade**: 발화자 스킨은 절대 왜곡하지 않음. 배경 shadow만 +2% 그린 시프트 (S3에서만).

## 7. 오디오 베드

- 저음 서브 pad (60–80Hz)로 인트로 전체 이어짐.
- 발화자 원본 음성 채널은 유지, 오버레이 임팩트 순간에 -3 dB 사이드체인 덕킹 (200ms 어택, 300ms 릴리스).
- S1: 팟캐스트 온에어 라디오 whir + tick 텍스처.
- S2: 크리스탈 shimmer + mechanical key tick.
- S3: 서브 임팩트 kick + 어퍼 shimmer + 티커 low-tick loop.

## 8. 등장인물 처리 세부

- 발화자는 원본 그대로. 크롭·재프레이밍 금지. 프레임 그대로 사용.
- 손 제스처(오른손 인사)가 S1 초반 0–2.5s에 자연스러운 "인트로 손인사" 역할 → 좌측 오버레이 등장 타이밍과 겹치지 않도록 좌 오버레이는 x≤560 유지 (손이 x≈650~870 영역에 있음).
- 시선은 카메라 정면 → 좌우 오버레이가 모두 시선 안쪽으로 들어오도록. 시선 바깥으로 오버레이가 나가면 인물이 "무시하는" 느낌.
- 발화자 얼굴에는 어떤 그래픽도 얹지 않음. 얼굴 반경 200px 세이프 존.

## 9. 로고 사용 규칙

- **NVIDIA 워드마크**: 공식 SVG, `--nv-green` 100%. 하단 좌측 고정, 크기 불변.
- **ChatGPT/OpenAI**: 실제 로고 금지. 커서 `▍`, 프롬프트 창 UI, `> Hello, GPT.` 텍스트 모티프로 대체. 헤더의 원+3점 실루엣은 일반적 채팅 UI 아이콘으로 인식되는 수준까지만.
- **KOSPI/CAC/DAX 등 지수 로고**: 이 8초 인트로에는 등장 안 함. S3 티커에서 텍스트 라벨(`> KOSPI`)로만 언급.
- **Apple 로고 (맥북)**: 프레임에 이미 노출되어 있음. 별도 오버레이 불필요, 원본 유지.
